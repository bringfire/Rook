Rook: licence and third-party notices
======================================

Rook is licensed under the MIT License.

  Notice: %LOCALAPPDATA%\Rook\app\LICENSE  [every installation]

Rook installs the third-party components below. Each "Notice" line gives the
installed location of a licence or notice file and the installer component that
puts it there. Lines marked "when installed" exist only if that component or
payload is on this machine.

Python 3.11.9 and Python packages
  The private CPython runtime is under the PSF License. Each Python package
  installed into Rook's runtimes keeps its licence in its *.dist-info folder;
  all of them are recorded in the Python runtime manifest.
  Notice: %LOCALAPPDATA%\Rook\python\cpython-3.11.9\LICENSE.txt  [when installed: private Python runtime]
  Notice: %LOCALAPPDATA%\Rook\app\python-runtime-manifest.json  [when installed: private Python runtime]
