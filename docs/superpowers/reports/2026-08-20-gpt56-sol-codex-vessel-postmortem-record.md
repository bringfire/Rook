sequence rather than a one-shot correct hypothesis:


## Attribution Preserved From Sol

The postmortem separates the result into distinct contributors:

- **Model judgment:** image-to-graph abstraction, C# selection, synthesis of
  incomplete evidence, formulation of discriminating tests, premise revision,
  and localized implementation repair.
- **User contribution:** prioritizing topology, approving C#, challenging the
  false-positive result, and supplying a marked visual correction that exposed
  the local connection rule.
- **Web contribution:** published totals, dimensions, sixteen-storey count,
  materials, and the dog-bone modular description. Sol identifies the
  sixteen-storey fact as materially affecting the corrected hypothesis.
- **Codex harness contribution:** native image access, persistent task context,
  web access, source editing, and preservation of the evolving collaboration.
- **Rook/Rhino/Grasshopper contribution:** authentic construction, compile and
  solve feedback, snapshots, diagnostics, and viewport evidence.
- **C# deterministic contribution:** graph generation, count and connectivity
  checks, and the added angular-locality and left/right-symmetry regression.

The central mechanism is not deterministic semantic supervision. Human visual
judgment exposed a false positive; model intelligence translated that criticism
into a measurable property; deterministic code tested the property against the
live output; and the same model revised its geometric premise.

## Comparison Value

This specimen supplies a stronger future comparison target than a final image
or pass/fail score alone. A matched run should preserve intermediate behavior
and compare whether another model can:

1. Ask questions that expose consequential ambiguity.
2. Separate published facts from inferred topology.
3. Choose an effective authoring representation.
4. Build a coherent graph abstraction before or during geometry generation.
5. Recognize that counts and connectivity can validate the wrong spatial graph.
6. Convert visual criticism into a discriminating executable test.
7. Replace a flawed premise rather than cosmetically patch its symptoms.
8. Preserve working geometry while repairing topology.
9. Combine quantitative, diagnostic, and viewport evidence.
10. State unresolved historical and geometric uncertainty honestly.

Useful ablations include the same broad task with web disabled, without the
marked user correction, or with a constrained authoring lane. These would be
new experiments, not facts established by this postmortem.
