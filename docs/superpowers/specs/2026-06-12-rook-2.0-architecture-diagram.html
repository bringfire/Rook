Invariants (the anchor — immovable)

  • Three layers, fixed language homes. The architecture is the layering — nothing left to rubberband on.
  • RookNative = sole in-Rhino surface. A router/connector may be the public MCP surface; nothing displaces RookNative inside Rhino.
  • The brain stays Python. KG · intent · bandits · DSPy · local-model orchestration never move to C#.
  • Center of gravity = local-first + KG + coordinated agents. Rook is not “another Rhino MCP server.”
  • Fewer, intent-shaped tools. ~300 typed routes stay substrate beneath an intent/KG surface — doubly so for the cheap tier (context economy is the lever).
  • Session ≠ Document ≠ Work Unit; Merge Contract is a DAG edge. Single-workstation bound.

Open questions (refinable — for review)

  • Q1 Layer-3 home: adopt McNeel’s C# router on the fork vs. extend Rook’s Python router with its patterns. Likely decided by cross-platform.
  • Q3 The empirical bet. Engram (Unreal domain, ~500 runs): B≈A confirmed; C≫D only conditional/modest (locals were already competent); context economy was the real variable; finetuning-as-shortcut backfired (12.5% actual vs 100% reported). Rhino is more niche → the probe is the real test.
  • Q7 Hermes topology: bottom-tier engine; Rook owns the top coordinator & identity. Mechanic (embed vs. subprocess) → the plan.
  • Q8 Cross-platform / Mac: Hermes does not solve Mac; the only non-degrading path is porting Layer 1 (C++) to macOS — the value (geometry/scenegraph/block analysis) is the portable part, the cost is permanent dual-platform native maintenance. Verify Mac C++ SDK parity first; workaround (Windows-in-the-loop) rejected.
  • Q4 Chirp home · Q5 UI surface · Q6 router→RookNative wiring.
  • Upstream posture: Hermes = ~0 core mutation (ride upstream via plugins); McNeel = adopt patterns + contribute up, avoid the router fork.

The pattern, one sentence: leverage a best-in-class substrate at every floor — McNeel (access) · Hermes (runtime) · RookNative (native) — and concentrate Rook’s irreducible effort on the one thing only an architect-who-codes can build: the knowledge graph + Rhino-domain intelligence + Chirp.
