# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## Summary

We are committed to providing a welcoming and inclusive environment for all contributors, regardless of background or experience level. By participating in this project, you agree to:

- Be respectful and constructive in all interactions
- Welcome newcomers and help them get started
- Focus on what is best for the project and its users
- Accept feedback gracefully and offer it kindly

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it by opening a private issue via GitHub's [private vulnerability reporting](../../security) interface, or by emailing the project maintainers.

All reports will be reviewed promptly and treated confidentially.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. Maintainers may take any action they deem appropriate, including warnings, temporary bans, or permanent bans from project spaces.
